Fusion 360 · Windows and Mac · version 1.3.1

Send to Bambu

A button in Fusion that sends every solid you can see to Bambu Studio. The file is already in millimeters. You do not select bodies. To leave a part out, hide it (click the light bulb in the browser).

Download SendToBambu.zip

Install it once

  1. 1

    Unzip the download

    Unzip SendToBambu.zip. You should see one folder named SendToBambu. Do not pull the files out of that folder, and do not rename it.

  2. 2

    Tell Fusion where the folder is

    In Fusion, open Utilities → Add-Ins → Scripts and Add-Ins. Click the Add-Ins tab. Next to My Add-Ins, click the green +. Choose the SendToBambu folder.

  3. 3

    Turn it on

    Select Send to Bambu. Check Run on Startup, then click Run. The button appears in the Design workspace, on a panel named Bambu Print.

Send a part

  1. 1

    Show only what you want printed

    Open your design. Turn the light bulb off on any body you do not want. You do not need to select the bodies.

  2. 2

    Click Send to Bambu

    Every visible solid goes: parts in the main component, and parts inside assemblies. Bambu Studio opens with them. Slice and print from there.

You already installed an older copy

  1. 1

    Stop it

    Scripts and Add-Ins → Add-Ins → Send to Bambu → Stop.

  2. 2

    Quit Fusion

    Quit the whole app. Closing the design is not enough. On a Mac use Fusion → Quit.

  3. 3

    Replace the folder

    Unzip the new download on top of the old SendToBambu folder and replace it. Open Fusion and click Run.

If Bambu Studio does not open

Click Bambu Print Settings, then Locate Bambu Studio, and pick the app:

Windows
C:\Program Files\Bambu Studio\bambu-studio.exe

Mac
/Applications/BambuStudio.app

On a Mac, choose the .app itself. Finder may look like it is a folder. That is normal.

If something looks wrong

The part is the wrong size

You still have an older copy. Stop it, replace the whole folder, quit Fusion, then Run.

It says no body was found

Turn the light bulb on for the solids you want. Hidden bodies and surfaces are skipped.

The button is missing

Scripts and Add-Ins → Add-Ins → Send to Bambu → Run. Check Run on Startup.

An error mentions scale_binary_stl

Fusion is still using the old files. Stop the add-in, replace the whole folder, quit Fusion, then Run.
